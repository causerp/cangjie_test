# Overview

This test measures ability of optimizing compiler to apply CHA optimizations in case of complex hierarchies.

# How to run

You can run each benchmark with the following command:

```
      program <repeats> [items] [iterations]
```

where default values for these parameters are 500 and 1000000 respectively.

To build and run each benchmark, you can just use `build_and_run_*.sh` scripts in java/cj/go directories.
You should also specify JET_DIR and LLVM_GC_DIR in some of them.

DO NOT MODIFY SOURCE CODE unless you hundred percent sure that your modification is safe.
